## 2. V11.1 每周回顾

### 2.1 用户体验

| 输入 | 期望 |
|---|---|
| 这周练得怎么样 | 本周练了几天、做了哪些、力量训练几天、有时长的训练合计多少分钟；对照建议还差什么，给一两句可执行的建议 |
| 上周我练了几次 | 同上，统计上周 |
| 我这周是不是练太少了 | 同上，结论要基于数字 |

### 2.2 设计（沿用红线、数据、指引、放开四层）

新增工具 `weekly_summary(week_offset)`：`0` 为本周，`-1` 为上周；周一到周日，按当前时间计算。

| 层 | 内容 | 谁保证 |
|---|---|---|
| 数据要对 | 训练天数、记录条数、力量训练天数、有时长训练合计分钟、练到的部位；全部由代码从训练记录计算，模型不自算 | 代码 |
| 数据要对 | 回复里的数字必须与工具返回一致 | 评测检查 |
| 红线 | 不虚构没有记录的训练；不做医疗或体态判断 | Prompt + 评测门禁 |
| 指引 | 对照 WHO 2020：每周 150～300 分钟中等强度有氧、至少 2 天力量训练；ACSM 2026：每周至少两次练到全部主要肌群 | Prompt |
| 放开 | 鼓励语气、下周建议怎么说 | 模型 |

**口径**（代码实现，写入工具输出，回复时如实说明）：

- **力量训练天数**：当天有带组数、次数或重量的完整记录。
- **有时长训练合计**：完整记录中 `duration_min` 之和。只统计用户记录了时长的，不按动作推算强度，因此不等于「中等强度有氧分钟」，回复中需说明是「记录了时长的训练」。
- **练到的部位**：按动作名称匹配动作库 v2 推断，顺序为：
  1. 先查**常用叫法表**：在动作库草稿中新增，例如「俯卧撑」→ 标准俯卧撑、「深蹲」→ 徒手深蹲、「平板」→ 平板支撑。
  2. 否则按名称包含关系匹配，匹配到多个时取共同部位。
  3. 匹配不到或没有共同部位，记为「未识别」，不猜。

  只用第 2 步会失真：实测「俯卧撑」匹配到的 4 个动作里含派克俯卧撑（练肩），共同部位只剩手臂，漏了胸。
- 只统计状态为「完整」的记录；「不完整」记录单列条数，提示用户补全。
- **按记录时间归周**：现有训练记录没有「哪天练的」字段，时间是说话时刻。周一说「上周六跑了 5 公里」会算进本周。回复中不需每次说明，但工具输出带此口径，被问到时如实解释。本期不改记录结构。
- `week_offset` 只支持 `0`（本周）与 `-1`（上周），其他值返回错误。

## 3. V11.2 动作指导

### 3.1 用户体验

| 输入 | 期望 |
|---|---|
| 深蹲怎么做 | 按动作库要点回答：练哪里、难度、要点与风险；有器械要求时给替代动作 |
| 平板支撑要注意什么 | 同上 |
| 药球砸地怎么做 | 动作库里没有：说明暂时不提供这个动作的指导，不自由发挥 |
| 我膝盖疼，深蹲怎么做 | 按红线 R5 建议咨询医生或专业人士，不给针对性指导 |

### 3.2 设计

新增工具 `get_action_guide(name)`：在动作库 v2 中按名称匹配，优先级为常用叫法 → 名称完全相同 → 名称包含。一个都没匹配到返回「库中没有」；匹配到多个时返回候选列表，由助手反问是哪一个（例如「卧推」对应哑铃卧推与杠铃卧推）。

| 层 | 内容 | 谁保证 |
|---|---|---|
| 红线 | 动作要点只能来自动作库；库外动作不教学 | 工具只返回库内内容 + Prompt + 评测门禁 |
| 红线 | 提到伤病等健康状况不给针对性指导（沿用 R5） | Prompt + 评测门禁 |
| 数据要对 | 部位、难度、器械、要点、替代动作原样来自动作库 | 代码 |
| 放开 | 用口语复述要点、补充鼓励 | 模型 |

助手 Prompt 升版本：删除「动作教学不支持」，改为「用 get_action_guide 回答，只讲工具返回的要点」。v4 保留。

## 4. 验收

按主人确认的节奏：**冒烟能跑通为主，不建数据集**。

| 项 | 标准 |
|---|---|
| 单测 | 周范围计算（跨周、周一、周日）、各统计口径、部位推断与「未识别」、不完整记录单列；动作匹配的唯一、多个、没有三种结果 |
| 既有回归 | 单测全过；六套既有 Runner Stub 结果不变 |
| Live 冒烟 | 第 2.1、3.1 节 7 条输入各跑 1 次，在调试台检查回复与 Trace；回复数字与工具返回一致 |
| 能力清单 | 同步更新，并在调试台首页展示 |

## 5. 明确不做

- 饮食记录与热量
- 按动作推算运动强度或消耗
- 跨多周的趋势图、目标设定、提醒推送
- 动作库以外的动作教学、视频或图片
- 多轮记忆（「那上周呢」接不上，仍为 V10 之后的候选）
