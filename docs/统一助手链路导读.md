# 统一助手链路导读

> 用途：在做[漏项自救归因实验](prd-v8-routine-reorder.md)（V8 PRD 第 14 节）之前，先弄清模型每一轮到底收到了什么。
> 创建：2026-09-25。状态：计划，待主人阅读。

## 1. 第一性原理：模型的决定由什么决定

模型不读代码。每一轮它的决定只取决于：

```text
模型的决定 = 模型能力 × 它这一轮收到的输入
```

「这一轮收到的输入」只有四块：

| 输入 | 是什么 | 在哪 |
|---|---|---|
| 系统 Prompt | 身份、能做什么、规则 | `backend/prompts/assistant_v5.txt` |
| 工具定义 | 工具名、用途说明、参数 | `backend/routine_agent.py`、`backend/tools.py` 的 `TOOL_SCHEMAS`；`backend/assistant.py` 为每个工具补上必填 `reason` |
| 消息历史 | 用户的话 + 之前每轮的调用与结果 | `backend/assistant.py` 的 `run_assistant`，每轮全量重发 |
| 工具返回 | 读取结果、报错 | `backend/routine_agent.py` 的 `_execute`、`backend/routine.py` 的 `validate_order` |

存储、Flask、页面、Trace 都是外壳：拼装输入、执行工具、守住底线，**不直接影响模型怎么想**。

Prompt 是核心，但只是四块之一；归因实验改的是另外三块（工具描述、读取结果、报错），Prompt 不动。

## 2. 阅读顺序（约 1 小时）

| 顺序 | 看什么 | 带着什么问题 |
|---|---|---|
| 1 | `backend/prompts/assistant_v5.txt` | 它被要求做什么？哪几条和训练安排有关？有没有提到暂停单元？ |
| 2 | 训练安排两个工具的定义（`routine_agent.py` 的 `TOOL_SCHEMAS`） | 「默认只返回进行中」「必须包含全部单元」分别在哪？模型要把两句连起来想，难不难？ |
| 3 | `_execute`（读取结果）与 `validate_order`（报错） | 读取结果长什么样？有没有提示还有隐藏项？报错多具体？ |
| 4 | `assistant.py` 的 `run_assistant` 循环 | 每轮拼了哪些消息？什么时候停？失败怎么回传？ |
| 5 | 对照 trace `t-ebfc7878-04d5-4b04-973c-39ab5a00e7c6` 与 [ReAct 实例](../eval/reports/ReAct实例-训练安排被拒后自我修正.md) | 每轮「输入」是否就是这四块的组合？ |
