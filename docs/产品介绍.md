# fit-agent（暂名）产品介绍

> 视角：**用户**。回答「它能帮我什么、为什么用它、怎么用」。
> 具体能做什么、每项的边界，以 [当前能力清单](当前能力清单.md) 为准；本文只讲为什么和怎么用，不重复列功能细节。
> 更新时机：定位、痛点、使用场景或「不做什么」发生变化时更新；功能增减只改能力清单。
> 更新：2026-09-25

## 一句话

**健身新手的口袋搭子：说一句话，帮你安排今天练什么、记下练了什么、看这周练得够不够、讲清动作怎么做。**

不用填表，不用装手表，不用先学一堆健身知识。

## 它是给谁的

- 想开始运动，但**不知道从哪练起**的人
- 练过几次，但**总坚持不下来、也记不住练过啥**的人
- 在家、在酒店、在健身房都想练，**条件每次不一样**的人

如果你已经有教练、有完整的训练周期，或者需要康复训练，它不适合你。

## 解决哪 4 个痛点

| 痛点 | 以前怎么办 | 用它怎么办 |
|---|---|---|
| **不知道今天练什么** | 刷半天视频，最后随便练两下 | 说一句「在家没器械，练半小时减脂」，马上给你一份「热身 → 训练 → 拉伸」的完整计划 |
| **练完懒得记** | 打开 App 一格格填，嫌麻烦就不记了 | 说一句「刚做了 100 个俯卧撑」，就记好了 |
| **不知道练得够不够** | 凭感觉，练多练少心里没数 | 问「这周练得怎么样」，告诉你练了几天、练到哪些部位，对照世界卫生组织的建议还差多少 |
| **动作不会、怕受伤** | 网上说法五花八门，不知道信谁 | 问「深蹲怎么做」，只讲核对过的要点和注意事项 |

这 4 件事连起来，就是一个新手每天用得上的闭环：

```text
今天练什么  →  练完一句话记下  →  周末看看练得够不够  →  动作不会随时问
```

## 为什么用它

**1. 一句话就行。** 记录、查询、要计划、问动作，全在一个聊天框里说人话，不用找菜单、不用填表单。

**2. 按你手上的条件现排。** 在家没器械就只排徒手动作，家里有哑铃就用上哑铃，在健身房就用健身房的器械。时间给多少就排多少，不会半小时的需求给你排出十分钟。

**3. 不乱给建议。** 这是它最在意的地方：

- 你说膝盖疼、怀孕了、刚做完手术，它不会硬给你排训练，而是建议你先问医生。
- 它只从一份核对过的动作库里选动作，不会给你编一个没听过的动作。
- 你没说在哪练、有什么器械，它会先问一句，而不是默认你有杠铃。

**4. 数字是真算出来的。** 这周练了几天、计划大概多少分钟，都是程序按你的记录算的，不是 AI「估个大概」。说不准的地方，它会直接告诉你口径，比如「这里只统计了你记了时长的训练」。

**5. 简单。** 不接手表、不搞社交、不塞一堆功能。只把上面 4 件事做好。

## 怎么用：4 个场景

| 场景 | 你可以这样说 |
|---|---|
| **下班回家，想动一动** | 「在家没器械，练 30 分钟减脂，我是新手」 |
| | 练完：「刚做了 100 个俯卧撑，还跑了 20 分钟」 |
| **出差住酒店** | 「住酒店只有一张床，想练 20 分钟」 |
| **到了健身房不知道练啥** | 「在健身房练腿，40 分钟，新手」 |
| | 不会某个动作：「高位下拉怎么做」 |
| **周日回顾一下** | 「这周练得怎么样」 |
| | 「上周我练了几次」 |

随时还可以问：「今天练了什么」「这周深蹲做了几次」「平板支撑要注意什么」。

一句话里说几件事也可以，比如「中午做了 100 个俯卧撑，再帮我看看这周练得怎么样」。

## 现在去哪用

目前是本地网页版：启动服务后打开 `http://localhost:5001/console`（启动方法见 [README](../README.md)）。

- 左边聊天，中间「我的面板」能看到训练安排和最近的记录。
- 首页会列出「现在能做什么」和示例句，点一下就能填进去。

## 它不做什么

| 不做 | 为什么 |
|---|---|
| **饮食记录和热量计算** | 热量要准确得有食物数据库，靠 AI 估算误差太大；宁可不做，也不给你一个不靠谱的数字 |
| **连接手表、手环** | 保持简单，说一句话记录就够了 |
| **社交、打卡排行** | 不是它要解决的问题 |
| **专业教练级的训练周期、康复方案** | 超出能力范围；提到伤病会建议你看医生 |

它给的计划和动作要点**不构成专业训练建议**。

## 现在还不够好的地方

说在前面，免得用的时候失望：

- **拉伸环节变化少**：同类需求下，拉伸常常是同几个动作（对口但不新鲜）；以后可能参考最近的计划来避免重复。
- **动作讲解比较简单**：每个动作目前只有一句要点，还不够细。
- **记不住上一句**：问完「这周练得怎么样」，再问「那上周呢」接不上，要说完整「上周练得怎么样」。
- **补记以前的训练会算到今天**：记录里没有「哪天练的」，周一补记上周六的训练，会算进本周。
- **计划时长会有出入**：说 30 分钟，排出来可能是 25 或 35 分钟，这是有意留的弹性。

这些也是后面改进的方向，按对用户的帮助大小排优先级。
