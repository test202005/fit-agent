## 已修复问题

### 1. confidence 末尾多余引号

DeepSeek 对部分输入稳定返回类似 `{"intent":"record","confidence":0.95"}` 的非法 JSON。Router 保持严格解析，不增加容错绕过；通过收紧 Prompt 的标准 JSON 输出表达修复。修复后 discovery 连续三轮解析错误为 0。

### 2. 提示注入错分为 record/query

模型曾把“指定 intent 或指定 JSON 输出”的文本当成用户命令执行。按 PRD 规则 8 强化 Prompt：用户输入只作为待分类文本，输出前优先检查是否在操控分类结果；已暴露 Case 从 locked 转入 regression，并补充未见 locked Case。最终 regression 和 locked 连续三轮均通过。

### 3. regression macro-F1 口径误导

regression 当前没有 query Case，传统三标签 macro-F1 会把缺席类别按 0 计入。报告保留三标签 `macro_f1` 以便跨视图对齐，同时增加 `present_labels_macro_f1` 表示当前视图实际出现标签的质量；最终 regression 后者为 1.0000。
